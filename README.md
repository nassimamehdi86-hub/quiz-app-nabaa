# تطبيق حفظ سورة النبأ 🌙

تطبيق تفاعلي (PWA) لحفظ سورة النبأ يضم:
- فيديو خريطة ذهنية لكل جزء (الجزء الأول ١-٢٠، الجزء الثاني ٢١-٤٠)
- ترتيب الآيات بالسحب والإفلات لكل مجموعة
- 📖 نافذة "عرض آيات المجموعة" تعرض الآيات كاملة بترتيبها الصحيح مع الاستماع لكل آية
- 🎙️ اختبار تسميع صوتي: يسجّل التلميذ الآية بصوته، يظهر ما قاله التطبيق نصًا، ويصحَّح الخطأ ولا يمكن الانتقال للآية التالية حتى يُتقن نطقها
- إمكانية تثبيت التطبيق على الهاتف كتطبيق مستقل (PWA)

---

## ✅ الفيديوهات

كلا الفيديوهين مُدمجان وجاهزان:
- `naba-part1.mp4` — الجزء الأول (٦:٣٠ دقائق)
- `naba-part2.mp4` — الجزء الثاني (٩:٢٥ دقائق) — تم ضغطه من ١٢٣ م.ب إلى ~١٤ م.ب دون فقدان وضوح النص، لتفادي حد الرفع في GitHub (١٠٠ م.ب)

## 📁 محتويات المجلد

| الملف | الوصف |
|---|---|
| `index.html` | التطبيق كاملًا |
| `manifest.json` | إعدادات تثبيت التطبيق (PWA) |
| `service-worker.js` | يسمح بعمل التطبيق بدون اتصال بعد أول تحميل |
| `icon-192.png` / `icon-512.png` | أيقونة التطبيق |
| `naba-cover.png` | صورة غلاف "سورة النبأ" بهوية التطبيق (للمشاركة/الاستخدام كصورة تعريفية) |
| `naba-part1.mp4` | فيديو الجزء الأول |
| `naba-part2.mp4` | فيديو الجزء الثاني |

## 🚀 خطوات الرفع على GitHub Pages

1. ادخلي إلى مستودعك (نفس نمط `nassimamehdi86-hub.github.io`) أو أنشئي مستودعًا جديدًا باسم مناسب، مثلًا `quiz-app-naba`.
2. ارفعي **كل** الملفات أعلاه (بدون مجلد `_build`) إلى جذر المستودع.
3. من إعدادات المستودع Settings → Pages، فعّلي النشر من الفرع `main` والمجلد `/root`.
4. رابط التطبيق سيصبح:
   `https://nassimamehdi86-hub.github.io/quiz-app-naba/`

### ملاحظة عن حجم الفيديو
حجم المجلد كاملًا الآن حوالي ٨٧ م.ب (أغلبه فيديو الجزء الأول). كل الملفات أقل من حد GitHub (١٠٠ م.ب للملف الواحد) فلن تواجهي أي مشكلة في الرفع.

## 📲 زر "ثبّت التطبيق"

الزر الذهبي أعلى الصفحة يظهر تلقائيًا في متصفحات Android/Chrome عندما يفتح المستخدم الرابط. على iPhone (Safari) لا يوجد هذا الزر تلقائيًا؛ يثبَّت عبر:
مشاركة (Share) ← "إضافة إلى الشاشة الرئيسية" (Add to Home Screen).

---

## 🎙️ ملاحظة حول اختبار التسميع الصوتي

يعتمد على خدمة التعرّف على الصوت المدمجة في المتصفح (Web Speech API)، وتعمل بشكل موثوق في:
- Chrome على أندرويد والحاسوب ✅
- Safari على iPhone: دعم جزئي/محدود حسب إصدار iOS

يحتاج التطبيق إذن الوصول للميكروفون من المتصفح عند أول استخدام.
